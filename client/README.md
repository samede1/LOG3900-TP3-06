# Description du module client 
Le module client comprend l'ensemble des fichiers du frontend. 

## Répertoires et fichiers
Le module est séparé en 2 répertoires: static et templates. Le répertoire static contient le fichier de style "style.css". Le répertoire template contient le fichier HTML "index.html". Ces fichiers permettent l'affichage de l'interface utilisateur de la calculatrice.

## Dépendances et exécution
Pour afficher l'interface utilisateur, suite au démarrage du serveur Flask dans le module server, il faut accéder au lien suivant dans un engin de recherche : 
    - http://127.0.0.1:5000
