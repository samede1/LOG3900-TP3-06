# Description du module tests
Le module tests contient les fichiers de tests des fichiers de logique métier du backend compris dans le module "server". 

## Répertoires et fichiers
Le module a 2 fichiers de tests: "test_app.py" et "test_operators.py".  


## Dépendances et exécution
La dépendance centrale du module est la bibliothèque de tests Pytest. Pour exécuter les tests et afficher leurs résultats dans le terminal, il faut utiliser la commande suivante :
    -  python -m pytest server/tests -v
